# Surge Module Hub

个人 Surge 模块移植实验库。目录包含来自 [可莉插件中心](https://hub.kelee.one/) 的 275 个条目，保留各原作者署名与来源。

网页地址：https://snowdegit.github.io/surge-module-hub/

**当前结果：273 项完成配置与脚本接口转换，2 项存在上游缺失或错误。所有模块均未完成真实 Surge / App 的逐项设备验证。** 静态检查通过不能证明所有 App 版本上的全部功能可用。

## 安装

用 Safari 打开网页，搜索模块，点击「安装」即可通过 `surge:///install-module?url=...` 唤起 Surge。也可在详情中复制模块地址手动添加。模块通过 GitHub 原始文件地址加载本仓库的脚本固定快照，无需伪造请求头下载上游脚本。

- 推荐使用 Surge 当前稳定版。含原生 jq 改写的模块至少需要 iOS 5.14+ / Mac 5.9+。
- 按模块需要启用 Rewrite、MITM 并安装信任自己的 CA；模块不会安装或替换证书。
- 部分模块包含定时任务、通用脚本、令牌或策略参数，应先阅读详情和源配置。
- 需要 `proxy_policy` 的模块，请在导入参数中填入你配置里已有的代理策略/策略组名称。
- 不要同时启用多个改写同一接口的同类模块。
- 首次建议先安装 HTTPDNS拦截器、广告平台拦截器，再逐个验证应用模块。
- 当前不承诺字幕服务、签到服务、第三方API、App特定版本或会员展示字段的长期有效性，也不赋予服务端会员权限。

### 转换说明

- Loon JSON/jq 重写转换为 Surge 原生 Body Rewrite；远程jq文件去除注释并内嵌。
- 固定响应转换为 Map Local；这与 Loon 新版固定响应的提前返回行为对应。
- 同方向的脚本合并为单个分发入口，按URL精确匹配，避免 Surge 每个阶段仅执行一个脚本导致覆盖。
- 参数默认值保留，转换为 Surge 模块参数。为 Loon 的对象参数与 Surge 字符串参数添加了接口桥接。
- 二进制脚本启用 binary-body-mode；原作者的多平台分支继续处理body/bodyBytes。
- 保存cron与generic任务声明；原来默认关闭的任务保持注释，不自动运行。
- 个别上游语法错误有明确修复记录；腾讯视频缺失的通用正则替换脚本按原配置中的明确参数重写。
- 未自动迁移旧Loon持久化数据/BoxJs数据库；相关功能可能需要在Surge重新设置。
- 不额外修改用户分流、节点、证书、系统代理或Reality服务。

## 目录

- `modules/`：模块入口。
- `scripts/`：生成的兼容分发层和保留的上游JavaScript。
- `data/`：较大的本地响应数据。
- `upstream/`：获取时的源配置、依赖与来源记录。
- `tools/`：抓取、构建、静态校验。
- `tests/`：隔离运行的行为和网页DOM测试（不是实际Safari/Surge设备测试）。

构建：`python3 tools/build.py`

静态校验：`python3 tools/validate.py`（需要Node.js和jq）。

行为测试：`node --test tests/behavior.test.cjs`。

## 发布

仓库需为 Public，Settings → Pages → Deploy from a branch → main → /(root)。`.nojekyll` 保证静态文件直接发布。模块与脚本地址固定为 `snowdegit/surge-module-hub`；若改仓库名称，修改 `tools/build.py` 的 BASE 并重新构建。
